

# DevTITANS 09 - HandsOn Final - Equipe 03

Bem-vindo ao repositório da Equipe 03 no DevTITANS! A equipe irá criar 2 joysticks com acelerômetro (que implementem o protocolo do SNES), integrá-los a uma Raspberry Pi terá o AOSP instalado e, através disso tudo, controlar 2 braços robóticos ao mesmo tempo.
